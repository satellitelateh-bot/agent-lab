# guesthouse_checkin (v2-assumptions)

TASK: Sea Breeze Guesthouse in Krabi Town has 8 rooms, check-in 14:00, check-out 11:00, self check-in with key box code sent on arrival day, free Wi-Fi, no breakfast, 5 minutes walk to the night market. Plan the guest messages, then write one check-in instruction message in both Thai and English.

**Guest Message Flow: Sea Breeze Guesthouse**

1. **Booking confirmation:** Thank guest; state 14:00 check-in and 11:00 check-out. [Owner to confirm: booking channel and confirmation timing]
2. **Pre-arrival (1-2 days before):** Remind of check-in time. Note no breakfast is included. Mention the night market is a 5-minute walk away.
3. **Arrival day:** Send the key box code for self check-in. [Owner to confirm: when the code is sent, e.g., morning of arrival]
4. **Check-in (from 14:00):** Give self check-in steps. [Assumed: room number is included with the key box code]
5. **During stay:** Share free Wi-Fi access. [Owner to confirm: network name and password]
6. **Checkout reminder (morning of departure):** Remind of 11:00 checkout. [Assumed: key return method, to be confirmed by owner]
7. **Post-stay:** Thank guest and invite feedback. [Owner to confirm: review link]

**Check-in Instruction Message: Content and Order**

1. **Arrival time:** Check-in is from 14:00. [Owner to confirm: early arrival handling]
2. **Key box code:** Sent on arrival day. [Owner to confirm: delivery channel and timing] [Placeholder: KEY BOX CODE]
3. **Self check-in steps:** [Owner to confirm: step-by-step instructions, including key box location and how to find the room]
4. **Wi-Fi:** Free access. [Owner to confirm: network name and password] [Placeholder: WI-FI DETAILS]
5. **Night market directions:** Five-minute walk from the guesthouse. [Owner to confirm: route description] [Placeholder: GUESTHOUSE ADDRESS]

Note: No breakfast is included, and this should be stated in the pre-arrival message, not this one.

**Parity rule** – The Thai version and the English version of the check‑in instruction must convey exactly the same information (same points, same order, same placeholders). No detail may appear in one language only.

**Pre‑writing checklist (items to confirm with the owner before drafting):**

1. ✔️ Exact check‑in start time (14:00) and early‑arrival handling.  
2. ✔️ Time and channel for sending the key‑box code on the arrival day.  
3. ✔️ Key‑box location (e.g., “next to the front gate”) and any label/number.  
4. ✔️ Step‑by‑step self‑check‑in procedure (enter code, retrieve key, open door).  
5. ✔️ Free Wi‑Fi SSID and password.  
6. ✔️ Confirmation that no breakfast is included (for pre‑arrival messages only).  
7. ✔️ Directions to the night market (5‑minute walk) – route description if needed.  
8. ✔️ Checkout time (11:00) and key‑return method (e.g., leave in box).  
9. ✔️ Any special instructions for guests with disabilities or large luggage.  

Only after all items are verified should the bilingual check‑in message be written.
